Receipt printer setup (Windows)

The cashier screen talks to USB thermal receipt printers directly from the browser (Chrome or Edge) — no separate print software needed. On Windows, the printer's normal manufacturer driver blocks this direct connection, so first you need to install a WinUSB driver for the printer using a free tool called Zadig.

Step 1 — Download Zadig

Download Zadig → zadig.akeo.ie

Official site. No installation needed — it's a single .exe you run directly.

  1. Plug the receipt printer into a USB port and turn it on.
  2. Run zadig-2.x.exe (no install required).
  3. In Zadig, open Options → List All Devices and tick the box.
  4. From the device dropdown, find your printer (often shows as "POS Printer", "USB Printer", or the manufacturer's name — Epson, Star, Bixolon, or a generic name for Chinese ESC/POS printers).
  5. In the driver box on the right, choose WinUSB.
  6. Click Install Driver (or Replace Driver if one is already listed).
  7. Wait for it to finish — this only needs to be done once per printer, per computer.

Pairing the printer with the POS

  1. Open the cashier screen (or Settings → Terminals in the back office).
  2. Click Pair printer — the browser shows a device picker.
  3. Select your printer from the list and click Connect.
  4. Use Test print to confirm — a short test receipt should print immediately.

This pairing is remembered per browser/computer. If you switch computers or reinstall the browser, pair again (Zadig step is not needed again unless the printer driver reverts).

Troubleshooting

  • Printer doesn't show up in Zadig: make sure "List All Devices" is checked in Options, and the printer is powered on and plugged in directly (not through an unpowered USB hub).
  • Printer doesn't show up in the browser's pairing picker: the WinUSB driver install (Zadig) didn't take — repeat the Zadig steps and pick the exact device again.
  • Nothing prints after pairing: use Test Print in Settings → Terminals; if that also fails, unplug/replug the printer and re-pair.
  • Windows reinstalled the original driver after a reboot: re-run Zadig and reinstall WinUSB for that device.

No thermal printer / skipping Zadig

A thermal printer isn't required. Without one paired, receipts print through the normal browser print dialog to any regular printer connected to the computer — slower and less "receipt-shaped," but works with zero setup.
